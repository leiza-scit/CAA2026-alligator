Dating machine

Enter how many sherds of each Arretine service type an assemblage holds. The page works out how probable each of the five chronological horizons is and shows the result as a bar chart and as an RDF graph that can be merged with the knowledge graph of this site. Everything is computed in your browser; nothing is sent anywhere.

1. The assemblage

The address of this page carries the counts (dating.html#0,0,13,27,60), so an assemblage can be shared as a link.

2. The attribution

Dirichlet-multinomial predictive likelihood: the pooled sherd counts of each horizon, plus the pseudocount, are the Dirichlet parameters; the five horizons have equal priors. The two pseudocounts differ by less than one percentage point for typical assemblages.

Reference counts of the five horizons

3. The result as a graph

The same result as RDF triples. The assemblage is a blank node: it has no identifier of its own and exists only in this graph. Each result is a CIDOC-CRM attribute assignment (E13) that assigns one horizon (lado:ChronologicalHorizon, crm:E4_Period) to the assemblage. Concepts (purple) and horizons are those of the graph on the overview, so the two can be merged. The heavy outline marks the most probable horizon.
