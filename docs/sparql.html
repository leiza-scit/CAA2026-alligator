Query the Arretine chronology graph

The graph behind the CAA 2026 contribution: 45 Arretine ware findspots in the north-western Roman provinces, each with a dated interval, grouped both by the seriation output and by archaeological horizon. Every query below runs in your browser — edit them and press Run.

There is no SPARQL endpoint and no server. The graph is fetched as a static file and parsed client-side with rdflib under Pyodide. That is deliberate: an archived copy of this repository stays queryable without a service having to be kept alive for it.

1. The five chronological horizons

The starting point for everything else: each horizon with its interval and how many findspots it holds. Horizon 1 is the latest, horizon 5 the earliest. The interval is the envelope of the horizon's findspots, from the earliest start to the latest end.

2. How the horizons relate to one another

The graph carries all twenty pairwise Allen relations between the horizons, so the sequence can be queried rather than read off a figure. Horizon 5 *meets* horizon 3 — one ends exactly where the other begins — while horizon 4 *contains* horizon 3 entirely.

3. Which findspots anchor the chronology?

Alligator marks a boundary as fixed when it rests on a historically dated event rather than on seriation alone. Only seven findspots carry such an anchor — and every horizon has at least one, which is what makes the sequence defensible.

4. Findspots that do not fill their horizon

Where every findspot carries the same dating, the horizon envelope describes the horizon exactly. Where members differ, the envelope is wider than any single findspot. This query returns only the findspots narrower than their horizon — none of them are in horizons 1 to 3, which is the quickest evidence that those three are internally homogeneous.

5. Which seriation clusters does each horizon absorb?

Both groupings live in the same graph, so one query can join them. A period cluster is computed — findspots the seriation gave an identical start and end year; a horizon is interpretive. Horizons 1 to 3 rest on a single cluster each, horizons 4 and 5 merge several, which is exactly why their envelopes are wider than their members.

6. Which findspots were still in use in AD 9?

The question the companion notebook works through in three different ways. Here it is resolved on the horizon level and in plain SPARQL: a findspot qualifies when its own interval covers AD 9, the year of the Clades Variana. Note the cast — rdflib will not compare xsd:gYear literals directly.

7. How well is each horizon linked to gazetteers?

A practical linked-data question: can every findspot be reconciled against an external authority? Gaps mark the places where this graph cannot yet be joined to Wikidata or Pleiades.
