From seriation output to a chronological knowledge graph

Supplementary materials for a CAA 2026 contribution on the chronology of Arretine ware (terra sigillata) findspots in the north-western Roman provinces. A Python pipeline reads the output of the Alligator seriation tool, merges it with findspot data, and produces a standards-compliant RDF knowledge graph together with the figures.

1. The knowledge graph

45 findspots, each carrying a dated interval, grouped in two different ways. Both groupings hold OWL-Time intervals and the full set of Allen relations between them, so the same temporal reasoning applies to either.

Vocabularies: CIDOC-CRM, OWL-Time, GeoSPARQL, SKOS and lado:. Findspots link to Wikidata and Pleiades. Download the graph (Turtle).

2. Query it in your browser

The query page runs SPARQL against the graph entirely in your browser: rdflib under Pyodide, against a static Turtle file. There is no endpoint and no server, the example queries are editable, and nothing you type leaves your machine.

That is deliberate for supplementary materials. An archived copy of this repository, unpacked years from now, stays queryable without a service having to be kept alive for it.

3. Reproduce it

Everything is rebuilt from the repository root with two commands. 

pip install -r requirements.txt
python py/main.py

The pipeline runs in a fixed order: the RDF step first (it clears output/), then the service-composition figures, then this query page. Figures are written as 300 dpi JPEG and pure-vector SVG, and the output is byte-reproducible — rebuilding without changing anything produces identical files, so a diff appears only when something really changed.
